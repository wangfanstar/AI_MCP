🔄 TX发送状态机

说明：LLR发送端状态机：LLR_OFF → INIT → ADVANCE ⇄ REPLAY → FLUSH。

→
FLUSH

状态转换条件：

  • LLR_OFF → INIT: llr_mode_remote == ON
  • INIT → ADVANCE: init_echo_received && replay_done
  • ADVANCE → REPLAY: nack_received || (replay_timer_expired && replay_ct < replay_ct_max)
  • REPLAY → ADVANCE: replay_done (完成重传)
  • REPLAY → FLUSH: replay_timer_expired && replay_ct == replay_ct_max
  • FLUSH → INIT: flush_done && re_init_on_discard

🔄 RX接收状态机

状态转换条件：

  • LLR_OFF → SEND_ACKS: llr_mode_local == ON && init_echo_sent
  • SEND_ACKS → SEND_NACK: expected_frame == FALSE (missing_frame || expected_frame_bad)
  • SEND_NACK → NACK_SENT: nack_sent == TRUE
  • NACK_SENT → SEND_ACKS: expected_frame == TRUE (收到正确序列号)
