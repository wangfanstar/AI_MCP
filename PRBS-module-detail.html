🔬 PRBS模块详细说明

1. PRBS模块功能原理

1.1 基本概念

PRBS (Pseudo-Random Binary Sequence) - 伪随机二进制序列，是一种用于测试和验证数字通信链路质量的测试模式。

1.2 功能描述

  • 生成器 (TX): 在PCS TX层生成PRBS测试模式，用于链路测试和误码率检测
  • 检测器 (RX): 在PCS RX层检测PRBS测试模式，用于链路质量评估
  • 标准: IEEE 802.3 Clause 82.2.4
  • 多项式: PRBS31 (x³¹ + x²⁸ + 1) 或 PRBS7/9/11/15/23
  • 应用: 链路质量测试、误码率(BER)测量、眼图测试

1.3 PRBS生成原理

PRBS生成器使用线性反馈移位寄存器(LFSR):
• PRBS31: x³¹ + x²⁸ + 1
• PRBS7: x⁷ + x⁶ + 1
• PRBS9: x⁹ + x⁵ + 1
• PRBS11: x¹¹ + x⁹ + 1
• PRBS15: x¹⁵ + x¹⁴ + 1
• PRBS23: x²³ + x¹⁸ + 1

3. RLM对PRBS的影响

影响方面 详细说明 解决方案
速率变化 RLM lane缩减后，200GR2模式一条lane的速率可能只有12.5G，但速率配置还是200GR2 需要调整PRBS检测器的速率配置，或使用自适应检测算法
码流准确性 RLM lane缩减后，PRBS的码流可能不准，因为数据被重新拼接 PRBS检测需要考虑RLM状态，在Lane Extend之后进行检测
丢包检测 RLM切换过程中可能出现数据包丢失，影响PRBS误码率统计 在RLM稳定状态（非SWITCH状态）下进行PRBS测试
测试模式 RLM使能时，PRBS测试模式需要跨越RLM层，测试整个链路 PRBS测试应包含RLM层的完整路径，而不仅仅是PCS层

5. PRBS与RLM交互流程

5.1 正常模式（RLM未使能或无故障）

  1. PCS TX生成PRBS测试模式
  2. PRBS数据直接通过RLM（透传模式）
  3. 数据发送到SerDes
  4. 接收端RLM透传数据
  5. PCS RX检测PRBS模式并计算误码率

5.2 RLM Lane缩减模式

  1. PCS TX生成PRBS测试模式（8条lane）
  2. RLM TX检测到故障，进行Lane Reduce
  3. 8条lane的PRBS数据被拼接在剩余可用lane上
  4. 数据通过减少的lane传输
  5. 接收端RLM RX进行Lane Extend
  6. PRBS数据恢复到8条lane
  7. PCS RX检测PRBS模式（需要注意速率变化）

5.3 关键注意事项

  • 速率配置: RLM lane缩减后，实际lane速率降低，但速率配置可能未更新
  • 码流连续性: RLM切换过程中PRBS码流可能中断
  • 测试时机: 建议在RLM稳定状态（REDUCE或正常模式）下进行PRBS测试
  • 误码统计: 需要考虑RLM切换期间的误码，区分正常误码和切换误码
