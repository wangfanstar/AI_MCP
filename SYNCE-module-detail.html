⏰ SYNCE模块详细说明

1. SYNCE模块功能原理

1.1 基本概念

SYNCE (Synchronous Ethernet) - 同步以太网，是一种从以太网数据流中恢复同步时钟信号的技术，用于网络时钟同步和频率传递。

1.2 功能描述

  • 位置: 仅在RX PCS层，在AM Detection之后、AM Removal之前
  • 机制: 基于64B/66B编码的同步头进行时钟恢复
  • 标准: ITU-T G.8261/G.8262, IEEE 802.3 Clause 82
  • 输出: 恢复的时钟信号用于系统时钟同步
  • 应用: 网络时钟同步、频率传递、时间同步基础（为1588提供时钟源）

1.3 时钟恢复原理

SYNCE时钟恢复机制:
• 基于64B/66B编码的Sync Header (01/10)
• 使用CDR (Clock Data Recovery) 电路
• 从数据流中提取时钟边沿
• 通过PLL (Phase Locked Loop) 锁定频率
• 输出稳定的系统时钟信号

3. RLM对SYNCE的影响

影响方面 详细说明 解决方案
时钟源选择 配置同步以太前需考虑是否使能RLM。如果开启RLM使能，并且是800GR8/400GR4/200GR2这三种速率的lane，从RLM里出；如果RLM使能关闭，或者非上述三种速率的lane，从PCS的lane出 根据RLM使能状态和速率配置，动态选择时钟源（rlm_sd_sync_ok信号）
时钟精度 RLM lane缩减后，同步以太恢复的时钟可能不准，因为数据流速率发生变化 在RLM稳定状态下进行时钟恢复，或使用多lane时钟平均算法
频率选择 RLM提供rlm_sd_sync_ok信号用于SYNCE模块的频率选择 SYNCE模块需要根据RLM状态和rlm_sd_sync_ok信号选择正确的时钟源
切换期间 RLM切换过程中，数据流可能中断，影响时钟恢复的连续性 使用时钟保持电路，在切换期间保持时钟输出稳定

4. SYNCE在系统中的位置

4.1 RX路径（唯一位置）

SerDes RX → PMA → FEC
↓
RLM RX (Lane Extend)
↓
PCS RX:
├─ AM Detection & Lane Alignment
├─ [SYNCE Clock Recovery] ← 在这里恢复时钟
├─ Lane De-skew
├─ AM Removal
├─ Descrambler
└─ 64B/66B Decoder

4.2 时钟输出应用

  • 为1588 PTP模块提供高精度时钟源
  • 为系统其他模块提供同步时钟
  • 网络频率同步和传递

5. SYNCE与RLM交互流程

5.1 RLM未使能模式

  1. 数据从SerDes直接到PCS RX
  2. SYNCE从PCS lane恢复时钟
  3. rlm_sd_sync_ok信号指示使用PCS时钟源
  4. 恢复的时钟用于系统同步

5.2 RLM使能模式（800GR8/400GR4/200GR2）

  1. 数据从SerDes经过RLM RX（Lane Extend）
  2. RLM提供rlm_sd_sync_ok信号
  3. SYNCE从RLM lane恢复时钟（根据rlm_sd_sync_ok选择）
  4. 恢复的时钟用于系统同步

5.3 RLM Lane缩减模式

  1. RLM进行Lane Extend，数据恢复到8条lane
  2. SYNCE从恢复后的数据流恢复时钟
  3. 时钟精度可能受影响（因为数据流速率变化）
  4. 需要时钟保持电路维持稳定性

5.4 关键注意事项

  • 时钟源选择: 必须根据RLM使能状态和速率配置正确选择时钟源
  • 时钟精度: RLM lane缩减后时钟精度可能下降，需要评估影响
  • 切换稳定性: RLM切换期间需要保持时钟输出稳定，避免系统时钟抖动
  • 1588依赖: 1588 PTP模块依赖SYNCE恢复的时钟，时钟质量直接影响时间戳精度
