CBFC: Credit-Based Flow Control (TX) UEC Specification 6.11.26
🔸 信用管理 (Credit Management)
• 功能: 管理虚拟通道(VC)的信用分配和消耗
• VC数量: 支持1-32个虚拟通道
• 信用计算: 基于接收端缓冲区大小和Cell Size
• 信用更新: 通过CC_Update和CF_Update消息同步
🔸 发送信用计数器 (S_VC_CC)
• 功能: 跟踪每个VC已发送的数据包数量
• 计数: 每个数据包消耗相应信用
• 更新: 定期通过CC_Update消息发送给接收端
• 同步: 与接收端R_VC_CC计数器对比
🔸 流控决策 (Flow Control Decision)
• 功能: 根据可用信用决定是否发送数据包
• 检查: 发送前检查VC是否有足够信用
• 阻塞: 信用不足时阻塞该VC的数据包发送
• 优先级: 支持不同VC的优先级调度
🔸 CC_Update消息生成
• 功能: 生成并发送信用计数器更新消息
• 格式: 64字节以太网帧，包含16个VC的CC值
• 频率: 可配置更新间隔
• 传输: 通过MAC Control层发送
🔸 CF_Update消息处理
• 功能: 接收并处理来自接收端的CF_Update消息
• 内容: 包含接收端可用信用信息
• 更新: 更新本地信用状态
• 格式: 8字节CtlOS控制有序集
输出: 等待启动...

🔸 发送缓冲区 (TX Buffer)
• 功能: 缓存待发送的数据包
• 容量: 可配置缓冲区大小
• 管理: FIFO队列管理
• 接口: 接收来自MAC Client的以太网帧
🔸 序列号管理 (SN Management)
• 功能: 为每个数据包分配唯一序列号
• SN格式: 根据UEC标准定义
• SN范围: 可配置序列号空间
• 同步: 与接收端SN同步机制
🔸 重传缓冲区 (Retransmission Buffer)
• 功能: 保存已发送但未确认的数据包
• 管理: 基于SN的索引管理
• 释放: 收到ACK后释放缓冲区
• 超时: 定时器超时触发重传
🔸 ACK/NACK处理
• 功能: 处理来自接收端的反馈信息
• ACK: 确认数据包成功接收
• NACK: 请求重传指定SN的数据包
• 处理: 更新重传缓冲区和发送状态
🔸 重传控制 (Retransmission Controller)
• 功能: 控制数据包的重传逻辑
• 触发条件: NACK或定时器超时
• 重传策略: 可配置重传次数限制
• 优先级: 支持优先级队列管理
🔸 定时器管理 (Timer Manager)
• 功能: 管理每个数据包的确认超时定时器
• 超时时间: 可配置RTO (Retransmission Timeout)
• 机制: 基于RTT动态调整
• 触发: 超时后触发重传流程
输出: 等待启动...

PCS: Physical Coding Sublayer IEEE 802.3 Clause 82/170
🔸 PCS TX Gearbox
• 输入: CGMII 数据流
• 功能: 数据位宽转换与对齐
• 输出: 64-bit数据块
🔸 64B/66B编码器
• 编码规则: 每64-bit数据 → 66-bit码块
• Sync Header: 2-bit (01/10) 用于同步
• Control Blocks: IDLE(/I/), START(/S/), TERMINATE(/T/), ERROR(/E/)
• 数据块类型: 0x1E (Data), 0x2D (Control), 0x33 (Ordered Set)
• 编码速率: 64/66 = 96.97%效率
Block Format:
[Sync:2b][Type:8b][Data:56b] → 66-bit
Data Block: 01 + 0x1E + 56-bit data
Control Block: 10 + Control_Type + 56-bit
🔸 Scrambler (扰码器)
• 多项式: G(x) = 1 + x³⁹ + x⁵⁸
• 目的: 频谱分散, 降低EMI
• 处理: 对66-bit块的64-bit数据部分扰码
• Sync Header不扰码
Scrambler LFSR: 58-bit shift register
🔸 AM Insertion (对齐标记插入)
• AM Pattern: 0x9A4A26B5C16D7E8F (固定码型)
• 插入间隔: 16383 blocks (可配)
• 每Lane独立AM
• Lane ID编码在AM中
• 功能: RX端Lane对齐与Deskew
AM[127:0] = {MARKER[95:0], LANE_ID[7:0], ..} Interval (800G): 16383 blocks ≈ 21μs
🔸 Lane Distribution (虚拟通道分配)
• 8 Virtual Lanes (VL0-VL7)
• 每Lane独立编码链
• Round-Robin分配策略
• Lane Marker跟踪
🔸 PRBS Generator (伪随机二进制序列生成器)
• 功能: 生成PRBS测试模式用于链路测试和误码率检测
• 标准: IEEE 802.3 Clause 82.2.4
• 多项式: PRBS31 (x³¹ + x²⁸ + 1) 或 PRBS7/9/11/15/23
• 模式: 可配置为测试模式或正常数据模式
• 应用: 链路质量测试、误码率(BER)测量、眼图测试
🔸 1588 PTP TX Timestamp (时间戳插入)
• 功能: 在PTP消息中插入精确时间戳
• 标准: IEEE 1588-2019 (PTPv2.1)
• 位置: 在64B/66B编码和Scrambler之后插入时间戳
• 触发: 检测到PTP帧的SFD (Start Frame Delimiter)
• 精度: 纳秒级时间戳精度，硬件实现
• 应用: 网络时间同步、频率同步、相位同步
• 影响: RLM使能时会影响HETS TX时戳计算，需要补偿
输出: 等待启动...

FEC: Forward Error Correction IEEE 802.3 Clause 91/119.2/171
🔸 FEC Encoder
算法: RS(544, 514) Reed-Solomon
• 信息位: 514 symbols × 10-bit = 5140-bit
• 校验位: 30 symbols × 10-bit = 300-bit
• 码字长度: 544 symbols = 5440-bit
• 纠错能力: 最多纠正15个symbol错误
• 编码率: 514/544 = 94.49%
• Pre-FEC BER要求: ≤ 5×10⁻⁵
• Post-FEC BER目标: ≤ 10⁻¹²
RS(544,514) Galois Field: GF(2¹⁰)
Generator Polynomial: g(x) = Π(x - α^i), i=0..29
Codeword = [Data:514 | Parity:30]
Latency: ~50-100ns
🔸 Transcoder (PCS→FEC)
• 66-bit PCS blocks → 10-bit FEC symbols
• 符号边界对齐
• Codeword组装
输出: 等待启动...

RLM: Reduce Lane Mode (TX) Internal Specification
🔸 RLM TX FIFO
• 功能: LANE REDUCE反压时吸收PCS发送的数据
• 深度: 2×128bit
• 管理: 产生PCS TX VLD信号
• 应用: 故障切换时的数据缓冲
🔸 RLM TX Lane Reduce
• 功能: 根据故障情况将8条lane数据拼接在无故障lane上
• 支持速率: 800GR8、400GR4、200GR2
• 处理: 插入故障切换码和RLM_AM码
• 切换: 反压前级FIFO，插入切换码流
🔸 RLM TX CRC Insert
• 功能: 对Lane reduce输出的数据进行CRC16校验计算
• 计算范围: 从AM_1后一拍到AM_2前一拍
• 插入: CRC校验码插入到AM_2的最高16bit
• 目的: 确保数据传输完整性
🔸 RLM TX Switch FSM
• 功能: 根据故障触发条件产生故障码
• 状态: INIT → SWITCH → REDUCE
• 触发: RLM RX故障码、serdes tx vld故障、软件配置故障
• 恢复: serdes恢复后自动或软件shut/unshut恢复
🔸 RLM TX Lane Swap
• 功能: 实现serdes tx lane swap功能
• 配置: 24bit配置（每3bit表示一条lane）
• 限制: RLM使能时不允许使用PCS lane swap
• 应用: 物理lane映射调整
🔸 RLM PCS TX2SDS AFIFO
• 功能: 8个异步FIFO完成MII时钟域到Serdes时钟域的跨时钟域处理
• 规格: 8深度×128位宽度（每个FIFO）
• 控制: 将满信号反压前级模块，阈值可配
• 启动: 解复位后接收到5拍数据后再开始读
🔸 RLM TX Find AM
• 功能: 适配1588-HETS功能，寻找AM码位置
• RLM不使能: 对PCS TX出口数据和AM PATTERN比对
• RLM使能: 对RLM TX出口数据和AM PATTERN比对
• 输出: 发送给HETS_TX进行时戳计算
输出: 等待启动...

800G: 8 Lanes × 106.25 Gbaud × 2 bit/symbol = 800G
PAM4 Levels: {-3σ, -σ, +σ, +3σ}

• Tap系数可配: 前3-5 taps
• 补偿信道损耗
• 提升高频分量
FFE Taps: C(-2), C(-1), C(0), C(1), C(2)
Typical: C(0)=0.7, C(-1)=0.15, C(1)=0.15
🔸 TX Driver (发送驱动器)
• 差分输出: 800-1200 mVpp
• Output Swing可调
• 电气规格: OIF-CEI-112G
• 连接: PCB Trace / Optical Module

• 错误超过纠错能力时标记UE

Correctable Errors: ≤ 15 symbols
UE Threshold: > 15 symbols
Latency: ~100-200ns
Post-FEC BER: 10⁻¹² (typical)

RLM: Reduce Lane Mode (RX) Internal Specification
🔸 RLM SDS2PCS RX AFIFO
• 功能: 8个异步FIFO实现serdes rx clk到mii clk的跨时钟域处理
• 规格: 8深度×128位宽度（每个FIFO）
• 控制: 非空即读
• 应用: 时钟域转换
🔸 RLM RX Lane Swap
• 功能: 实现serdes rx lane swap
• 处理: 只对数据和数据有效信号进行swap
• 限制: RLM使能时不允许使用PCS lane swap
• 配置: 24bit配置（每3bit表示一条lane）
🔸 RLM RX Lane Lock
• 功能: 移位解析RLM_AM码字，完成RLM_LANE_LOCK
• AM Pattern: 0x9A4A26Bx (x表示lane编号)
• 处理: 通过数据移位32bit和RLM_AM_PATTERN比较找到AM位置
• 状态机: GET_BLOCK → COUNT_NEXT → TWO_GOOD
• CRC校验: 每两个AM码之间的数据CRC校验
🔸 RLM RX Deskew
• 功能: 对齐统一接口的多条LANE的RLM_AM码
• FIFO: 8个FIFO，160深度×128bit位宽（SRAM搭建）
• 状态机: DESKEW → ALIGN_ACQUIRED → DESKEW_FAIL
• 处理: 根据lane number对8条lane的数据进行reorder
• 输出: 对齐后的数据发送给PCS RX
🔸 RLM RX Switch FSM
• 功能: 识别故障码到做切换处理的状态切换
• 状态: INIT → LOCK → SWITCH → REDUCE
• 触发: SERDES deskew失败、CPLD故障、rx vld拉低、sigdet拉低、软件配置故障
• 处理: 识别切换码流，切换到可用LANE上接收数据
🔸 RLM RX Lane Extend
• 功能: 将可用LANE的数据解析扩展到原来的所有LANE上
• 支持速率: 800GR8、400GR4、200GR2
• 处理: 接收RX SWITCH FSM的切换信号，做数据扩展
• 输出: 发送给PCS RX，并产生PCS RX VLD信号
🔸 RLM RX Find AM
• 功能: 适配1588-HETS功能，寻找AM码位置
• RLM不使能: HETS RX使用PCS LANE LOCK出口的AM_POS信号
• RLM使能: HETS RX使用RLM LANE LOCK输出的FIND_AM信号打时戳
• 输出: 发送给HETS_RX_TOP进行时戳计算
输出: 等待启动...

Skew Tolerance: ±40 UI (800G)
FIFO Control: Write on AM, Read after align
